# 飞书到款认领系统 MVP

这是根据需求文档搭建的第一版纵向切片，用于先验证核心流程：

- 财务导入 CSV/表格文本，并上传原始凭证附件
- 财务确认后进入认领池
- 普通用户只能关键词搜索，不能浏览全量流水
- 普通用户提交认领
- 财务查看全量、处理异常、驳回、关闭
- 搜索、导入、确认、认领、处理动作全部写入日志

## 启动

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

打开：

- 普通认领页：http://127.0.0.1:8000/search
- 财务后台：http://127.0.0.1:8000/admin?role=finance&user=finance&name=财务管理员

## 导入格式

支持 CSV、TSV、复制自表格的文本。建议第一行带表头。

财务后台也支持上传原始凭证附件，用于留存银行截图、PDF 或表格原文件。当前附件只做保存和查看，不自动识别内容。

支持的附件格式：

- `.png`
- `.jpg` / `.jpeg`
- `.pdf`
- `.csv`
- `.xls` / `.xlsx`

单个附件大小限制：20MB。

可识别的表头包括：

- 到款日期 / 日期 / date
- 到款时间 / 时间 / time
- 付款方名称 / 付款方 / payer
- 到款金额 / 金额 / amount
- 银行备注 / 摘要 / 备注 / note
- 收款账户 / account
- 流水号 / 回单号 / serial_no

示例：

```csv
到款日期,付款方名称,到款金额,银行备注,流水号
2026-06-10,北京某某教育科技有限公司,98000,创新年会合作款,ABC001
2026-06-10,上海某某文化传播有限公司,15000,论坛报名费,ABC002
```

## 当前实现边界

第一版暂时不直接接入飞书机器人、飞书身份、OCR 或大模型拆单。身份使用页面参数和表单字段模拟：

- `role=finance`：财务管理员
- 普通用户默认只能进入搜索页，不能访问财务后台

后续接入飞书时，需要把模拟身份替换为飞书应用鉴权结果，并把提醒和搜索入口迁移到机器人或飞书卡片。

## 下一步建议

1. 接入飞书用户身份，绑定财务管理员和部门认领人。
2. 接入 OCR/AI，从上传的图片、PDF 或 Excel 中自动拆单。
3. 将普通用户搜索结果改为飞书卡片。
4. 增加定时提醒任务。
5. 根据试点反馈决定是否做付款方/备注脱敏。
