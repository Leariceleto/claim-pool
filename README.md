# 飞书到款认领系统

财务到款认领系统是一个内部工具：财务导入银行流水后，各部门同事通过飞书登录，搜索并认领属于自己部门、中心和项目的到款。系统会记录每一步操作，方便财务确认、追溯和对账。

当前版本已支持普通认领、部分认领、分摊认领、本人取消认领、跨部门参与范围、到款公司记录和管理后台处理。

## 核心功能

- **飞书登录**：同事通过飞书 OAuth 登录；敏感操作只信签名会话，不信 URL 或表单里的角色。
- **认领搜索**：按客户名、付款方、金额、备注或到款 ID 搜索；搜索结果展示金额和到款公司。
- **待认领列表**：展示待认领和部分认领中的款项，支持按到款日期筛选。
- **到款公司**：记录集团下实际收到款的收款主体，导入、编辑、导出、看板和认领明细都会展示。
- **三级分类认领**：按「部门 → 中心 / 小组 → 项目」三级联动选择，分类来源是 `catalog.json`。
- **分摊认领**：一笔到款可拆成多条分摊明细，分别提交到不同部门、中心和项目，适合客户批量采购多个产品的场景。
- **本人取消认领**：用户可在个人中心取消自己的可取消认领，款项自动回到待认领或按剩余认领重新计算状态。
- **个人中心与看板**：普通用户可看本部门范围数据；支持管理员配置额外参与范围，用户可切换“全部角色 / 主身份 / 单个参与范围”。
- **管理后台**：导入流水、确认入池、编辑到款、处理认领冲突、驳回、关闭、批量关闭、导出今日 CSV、管理成员身份和参与范围。
- **操作审计**：搜索、导入、认领、分摊、取消、驳回、授权等关键动作都会写入日志。

## 启动

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app:app --reload --port 8000
```

打开：

- 认领搜索页：http://127.0.0.1:8000/search
- 分摊认领页：http://127.0.0.1:8000/split-claim
- 个人中心：http://127.0.0.1:8000/me
- 管理后台：http://127.0.0.1:8000/admin

完整飞书登录需要 HTTPS 公网地址，并且 `.env` 的 `FEISHU_REDIRECT_URI` 必须与飞书开发者后台的重定向 URL 完全一致。

## 导入格式

支持 CSV、TSV、复制自表格的文本，以及上传 Excel / PDF / 图片凭证。PDF 和 Excel 会自动尝试识别流水；银行常见的“内容为 .xlsx、后缀为 .xls”的导出文件也支持上传识别。

支持的附件格式：

- `.png`
- `.jpg` / `.jpeg`
- `.pdf`
- `.csv`
- `.xls` / `.xlsx`

单个附件大小限制：20MB。

可识别的表头包括：

- 到款日期 / 日期 / date
- 到款时间 / 时间 / time
- 付款方名称 / 付款方 / payer
- 到款公司 / 收款公司 / 收款方 / receiver_company
- 到款金额 / 金额 / amount
- 银行备注 / 摘要 / 备注 / note
- 收款账户 / account
- 流水号 / 回单号 / serial_no

示例：

```csv
到款日期,付款方名称,到款公司,到款金额,银行备注,流水号
2026-06-10,北京某某教育科技有限公司,北京蒲公英未来科技有限公司,98000,创新年会合作款,ABC001
2026-06-10,上海某某文化传播有限公司,重庆云族科技有限公司,15000,论坛报名费,ABC002
```

## 部署提醒

正式部署请看 [DEPLOY.md](DEPLOY.md)。上线前重点确认：

- `CLAIM_POOL_DB` 和 `CLAIM_UPLOAD_DIR` 指向持久磁盘。
- `.env`、数据库、上传附件不能进 git。
- 飞书后台的重定向 URL、网页应用主页地址、环境变量里的正式域名要一致。
- 飞书应用可见范围要开放给实际使用同事。
